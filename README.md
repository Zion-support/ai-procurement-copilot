# AI Procurement Copilot

AI Procurement Copilot compares suppliers, drafts RFQs, and flags spend anomalies before they hit the P&L.

Part of the **Zion AI App Network** — a family of free AI tools by [Zion Tech Group](https://ziontechgroup.com).

## Features
- Supplier side-by-side comparison (price, lead time, risk, ESG)
- One-click RFQ drafting from BOMs and scope notes
- Spend anomaly detection across vendors and categories
- Contract renewal reminders via [Contract Renewal Radar](https://github.com/Zion-support/contract-renewal-radar)
